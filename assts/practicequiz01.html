Question 2

Write two methods called countDownRec and countDownLoop that each an integer n and print every number from n down to 1. countDownRec should be solved recursively, and countDownLoop should be solved with a loop.

For example:

countDown(4);

Should print:

4
3
2
1

Solution:

Possible recursive solution:

public static void countDown(int n) {
    if (n == 0) {
        return;
    }

    System.out.println(n);
    countDown(n - 1);
}

Possible loop solution:

public static void countDown(int n) {
    while (n > 0) {
        System.out.println(n);
        n--;
    }
}

 
 
 

Question 3

This method is supposed to return the sum of the numbers from 1 through n.

public static int sum(int n) {
    if (n == 0) {
        return 0;
    }

    return sum(n - 1);
}

What is the bug? How can you fix it?

Solution:

The recursive step needs to include n.

public static int sum(int n) {
    if (n == 0) {
        return 0;
    }

    // Next line is the fix
    return n + sum(n - 1);
}
