= Question 2: Code Tracing

Consider the following program.

[source]
----
class Counter {
  private int count;

  public Counter(int start) {
      count = start;
  }

  public void increment() {
    count++;
  }

  public int getCount() {
    return count;
  }

}
----

What is printed by the following code? Show the values of a and b after each statement.

[source]
----
Counter a = new Counter(3);

Counter b = a;

b.increment();


System.out.println(a.getCount());


b = new Counter(10);

a.increment();


System.out.println(b.getCount());

System.out.println(a.getCount());

= Question 3: W

Consider the following program.

[source]
----
class ReferencePractice {
    public static void mystery(int[] data, int number) {
        data[0] = number;
        number = 20;

        data = new int[]{7, 8, 9};
        data[1] = 100;
    }

    public static void main(String[] args) {
        int x = 5;
        int y = x;

        int[] a = {1, 2, 3};
        int[] b = a;

        y = 10;
        b[2] = 15;

        mystery(a, x);

        System.out.println(x);
        System.out.println(y);
        System.out.println(a[0]);
        System.out.println(a[1]);
        System.out.println(b[2]);
    }
}
----

1. Write the exact output of the program, one value per line.

2. Draw a memory diagram showing `a` and `b` and the array they refer to at the end of `main()`.

3. Explain why changing `y` does not change `x`, but changing `b[2]` changes the array accessed through `a`.

4. Does the statement `data = new int[]{7, 8, 9}` (in the `mystery()` function) affect the array `a` in `main()`
refers to? Why or why not?

= Question 4: Write a Method

We are writing a program that processes a two-dimensional array representing seats in a theater. 
Each seat contains a character:

* `X` represents an occupied seat.
* `O` represents an available seat.

For example:

[source]
----
char[] seats = {
                  {`X`, `O`, `X`, `O`},
                  {`X`, `X`, `O`, `O`},
                  {`O`, `O`, `O`, `X`}
               };
----

1. Write a method called `countAvailable()` that takes a 2D character array and returns the total number
of available seats.

2. Write a method called `hasAvailableSeat()` that takes a single row of seats and returns true if at
least one seat is available, and false otherwise.

3. Use `hasAvailableSeat()` to write another method that determines whether any
row in the theater contains an available seat. It should take in a 2D character array and returns
true if any row contains an available seat, and false otherwise.
