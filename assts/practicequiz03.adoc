= Question 2: Code Tracing

Consider the following program.

[source]
----
class Counter {
  private int count;

  public Counter(int start) {
      count = start;
  }

  public void increment() {
    count++;
  }

  public int getCount() {
    return count;
  }

}
----

What is printed by the following code? Show the values of a and b after each statement.

[source]
----
Counter a = new Counter(3);

Counter b = a;

b.increment();


System.out.println(a.getCount());


b = new Counter(10);

a.increment();


System.out.println(b.getCount());

System.out.println(a.getCount());

= Question 4: Inheritance & Overriding

Consider the following program.

[source]
----
class Vehicle {

    private int speed;

    public Vehicle(int speed) {
      this.speed = speed;
    }

    public int getSpeed() {
      return speed;
    }

    public void move() {
      System.out.println("Moving at " + speed);
    }
}


class Bike extends Vehicle {

    public Bike(int speed) {
      super(speed);
    }

    @Override

    public void move() {
      System.out.println("Pedaling at " + getSpeed());
  }
}
----

Answer the following questions.

* What is printed?

[source]
----
Vehicle v = new Vehicle(10);

Bike b = new Bike(15);


v.move();

b.move();
----

* Explain what `super(speed)` does in the `Bike` constructor.

{nbsp} +

* If we remove the overridden `move()` method from `Bike`, what will `b.move()` print?
