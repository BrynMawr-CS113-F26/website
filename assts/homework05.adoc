= Overview

For our final programming homework, you will implement a small reading 
tracker that stores information about books and articles, reads records 
from a file, and produces a reading summary.

The goal is to bring together concepts from throughout the semester: 
classes, constructors, inheritance, interfaces, polymorphism, arrays,
loops, methods, and file input.

You do not need maps, sorting, a graphical interface, or any additional
Java libraries beyond those used for file input.

= 1. Define the Interface

Create a java file: `ReadableItem.java` with the following code.

[source, subs="quotes"]
----
public interface ReadableItem {
    int getReadingMinutes();
}
----

The method returns the estimated time required to finish reading an item.

---
[discrete]
= 2. Define the Abstract Parent Class

Create an abstract class named `ReadingItem` that implements `ReadableItem`.

Requirements:

- Private fields: `String title` and `int pages`.
- Constructor: `ReadingItem(String title, int pages)`.
- Public getters: `String getTitle()` and `int getPages()`.
- Abstract public method: `String getType()`.

Do not provide an implementation of `getReadingMinutes()` in this class. Each concrete subclass will implement the method differently.

---
[discrete]
= 3. Implement Two Subclasses

Create a class named `Book` that extends `ReadingItem`.

Requirements:

- Constructor: `Book(String title, int pages)`.
- `getType()` returns `"BOOK"`.
- `getReadingMinutes()` returns three minutes per page.

Create a class named `Article` that extends `ReadingItem`.

- Constructor: `Article(String title, int pages)`.
- `getType()` returns `"ARTICLE"`.
- `getReadingMinutes()` returns five minutes per page.

For this assignment, the reading rates are fixed estimates, not realistic predictions of any particular person's reading speed.

Use the parent constructor rather than duplicating inherited fields. Use `@Override` for overridden methods.

[discrete]
= 4. Read the Input File

Create a class named `ReadingTracker`. Implement the following method:

[source]
----
public static ReadingItem[] loadItems(String filename)
        throws FileNotFoundException
----

The input file begins with an integer specifying the number of records. Each following record consists of a type, a title (one word, with underscores allowed), and a positive integer page count.

Example `reading.txt`:

[source]
----
5
BOOK The_Hobbit 300
ARTICLE Operating_Systems 12
BOOK Kindred 264
ARTICLE Computer_History 8
BOOK Coraline 160
----

Your method should:

1. Open the file using a `Scanner` and `File`.
2. Read the number of records and allocate an array of the appropriate size.
3. Read each record and construct either a `Book` or an `Article`.
4. Store each object in the array.
5. Close the scanner and return the array.

You may assume all files are correctly formatted, contain only the two supported item types, and have nonnegative record counts. A file containing only `0` represents an empty reading list. Preserve titles exactly as provided.

---
[discrete]
= 5. Analyze the Reading List

Implement these public static methods in `ReadingTracker`.

Total Reading Time:

[source]
----
public static int totalReadingMinutes(ReadingItem[] items)
----

Return the sum of the estimated reading times of all items. Return `0` for an empty array.

Count Items By Type:

[source]
----
public static int countByType(ReadingItem[] items, String type)
----

Return the number of items whose type exactly matches `type`. Use `.equals()` for string comparison. Return `0` when no items match.

Find the Longest Read:

[source]
----
public static ReadingItem longestRead(ReadingItem[] items)
----

Return the item with the greatest estimated reading time. If multiple items tie, return the first one. Return `null` for an empty array.

[discrete]
= 6. Putting It All Together

Implement `main` in `ReadingTracker.java`.

Your program should load `reading.txt`, print the items in input order, and display a summary.

For the example input file, the output should be:

[source]
----
BOOK The_Hobbit: 300 pages, 900 minutes
ARTICLE Operating_Systems: 12 pages, 60 minutes
BOOK Kindred: 264 pages, 792 minutes
ARTICLE Computer_History: 8 pages, 40 minutes
BOOK Coraline: 160 pages, 480 minutes
Total reading time: 2272 minutes
Books: 3
Articles: 2
Longest read: The_Hobbit
----

For an empty file, the output should be:

[source]
----
Total reading time: 0 minutes
Books: 0
Articles: 0
Longest read: None
----

Your `main` method must catch a `FileNotFoundException` if the input file cannot be opened, print `Unable to open reading.txt`, and terminate normally.
