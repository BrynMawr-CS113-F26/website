= 1. Library
A library stores many kinds of items. A general library item has a title and an identification number. A book is a special kind of library item that also has an author.

Create three files in the your `/lab8` directory: `LibraryItem.java`, `Book.java`,
and `Main.java`. You can use the `touch` command to do this. For example: `touch Book.java`.

= 4. Test your classes


Copy the following code into the `Main.java` file.
Follow the same instructions from part 2 to format your code before you begin programming.

[source, subs="quotes"]
----
public class Main {
    public static void main(String[] args) {
        LibraryItem item = new LibraryItem("Map", 5);
        Book book = new Book("The Hobbit", 12, "J.R.R. Tolkien");

        System.out.println(item.describe());
        System.out.println(book.describe());

        // TODO 7: Make a second Book of your choice.
        // Print its title, author, and description.

        // TODO 8: Predict the output of the next two lines.
        LibraryItem anotherItem = book;
        System.out.println(anotherItem.describe());

}
----

Compile/run from the directory containing all three files:

[source, subs="quotes"]
----
javac LibraryItem.java Book.java Main.java
java Main
----

Expected output for the supplied objects:

[source, subs="quotes"]
----
Item #5: Map
Book #12: The Hobbit by J.R.R. Tolkien
----

The later output depends on your own second book; the final `anotherItem.describe()` 
should use the `Book` version.
