Question 2: Code Tracing

Consider the following program.

class Counter {
  private int count;

  public Counter(int start) {
      count = start;
  }

  public void increment() {
    count++;
  }

  public int getCount() {
    return count;
  }

}

What is printed by the following code? Show the values of a and b after each statement.

Counter a = new Counter(3);

Counter b = a;

b.increment();


System.out.println(a.getCount());


b = new Counter(10);

a.increment();


System.out.println(b.getCount());

System.out.println(a.getCount());

Question 4: Inheritance & Overriding

Consider the following program.

class Vehicle {

    private int speed;

    public Vehicle(int speed) {
      this.speed = speed;
    }

    public int getSpeed() {
      return speed;
    }

    public void move() {
      System.out.println("Moving at " + speed);
    }
}


class Bike extends Vehicle {

    public Bike(int speed) {
      super(speed);
    }

    @Override

    public void move() {
      System.out.println("Pedaling at " + getSpeed());
  }
}
