= 1. Bank Account

We want to represent a simple bank account in Java. Each BankAccount has an owner and a balance. 
Other code should not be able to arbitrarily overwrite the balance. Instead, the account provides methods
for depositing and withdrawing money.

For this introductory exercise, we’ll use double for balances to practice numeric instance fields. 
Real financial software generally uses integer cents or a decimal money type, not double.
Lets begin by making sure you are familiar with tic tac toe. If you aren't, briefly look
at wikipedia.
