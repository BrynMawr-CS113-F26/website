= Question 1: Follow the Array

Consider the following Java program.

[source]
----
public class ArrayPractice {
    public static void change(int[] nums, int value) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] % 2 == 0) {
                nums[i] += value;
            } else {
                nums[i] -= 1;
            }
        }
    }

    public static int calculate(int[] nums) {
        int total = 0;

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > 4) {
                total += nums[i];
            } else {
                total += 2;
            }
        }

        return total;
    }

    public static void main(String[] args) {
        int[] values = {2, 5, 6, 3};

        change(values, 3);

        int result = calculate(values);

        change(values, 1);

        System.out.println(result);
        System.out.println(values[0]);
        System.out.println(values[2]);
    }
}
----

1. What are the contents of `values` immediately after the first call to `change()`?

2. What value does `calculate()` return? Show how `total` changes in the loop.

3. What are the contents of `values` after the second call to `change()`?

4. What exactly does the program print?

5. Does the second call to `change()` affect the value restored in `result`? Explain your reasoning.

= Question 2

Write two methods called `countDownRec` and `countDownLoop` that each an integer `n` and print every number from `n` down to `1`.
`countDownRec` should be solved recursively, and `countDownLoop` should be solved with a loop.


For example:

[source]
----
countDown(4);
----

Should print:

[source]
----
4
3
2
1
----

**Solution:**

Possible recursive solution:

[source]
----
public static void countDown(int n) {
    if (n == 0) {
        return;
    }

    System.out.println(n);
    countDown(n - 1);
}
----

Possible loop solution:

[source]
----
public static void countDown(int n) {
    while (n > 0) {
        System.out.println(n);
        n--;
    }
}
----

= Question 3

This method is supposed to return the sum of the numbers from `1` through `n`.

[source]
----
public static int sum(int n) {
    if (n == 0) {
        return 0;
    }

    return sum(n - 1);
}
----

What is the bug? How can you fix it?

**Solution:**

The recursive step needs to include `n`.

[source]
----
public static int sum(int n) {
    if (n == 0) {
        return 0;
    }

    // Next line is the fix
    return n + sum(n - 1);
}
----
