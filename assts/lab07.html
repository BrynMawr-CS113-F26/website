1. Bank Account

We want to represent a simple bank account in Java. Each BankAccount has an owner and a balance. Other code should not be able to arbitrarily overwrite the balance. Instead, the account provides methods for depositing and withdrawing money.

For this introductory exercise, we’ll use double for balances to practice numeric instance fields. Real financial software generally uses integer cents or a decimal money type, not double. Lets begin by making sure you are familiar with tic tac toe. If you aren’t, briefly look at wikipedia.

3. Testing Your Code

Create a second file called BankAccountTest.java. Copy the following code into the file. Follow the same instructions from part 2 to format your code before you begin programming.

public class BankAccountTest {

    public static void main(String[] args) {

        BankAccount milo = new BankAccount("Milo", 100.0);

        BankAccount alex = new BankAccount("Alex", 50.0);



        System.out.println(milo.getOwner());   // Milo

        System.out.println(milo.getBalance()); // 100.0



        System.out.println(milo.deposit(25.0)); // true

        System.out.println(milo.getBalance()); // 125.0



        System.out.println(milo.withdraw(30.0)); // true

        System.out.println(milo.getBalance());  // 95.0



        System.out.println(milo.withdraw(200.0)); // false

        System.out.println(milo.getBalance());   // still 95.0



        System.out.println(alex.getBalance()); // still 50.0

    }

}

Compile and run:

javac BankAccount.java BankAccountTest.java

java BankAccountTest

Your code should correctly handle all of these (the above code tests these exact conditions):

● Create an account with a starting balance of 100.0.

● Deposit 25.0: the balance becomes 125.0.

● Withdraw 30.0: the balance becomes 95.0.

● Attempt to withdraw 200.0: return false; balance stays 95.0.

● Attempt to deposit 0.0 or a negative amount: return false; balance stays unchanged.

● Construct an account with a negative starting balance: initialize it to 0.0.

● Update one account: a different account’s balance does not change.
