= Objectives

By the end of this lab, you should be able to:

- Implement a Java interface in multiple classes.
- Use an abstract class to share state and behavior among subclasses.
- Read records from a text file using `Scanner`.
- Store objects of different subclasses in a single array and invoke methods polymorphically.

= Overview

In this lab, you will build a small campus event tracker. Different types of events have different durations, but every event has a name and can report its duration in minutes.

Work through the sections in order. Compile and test your program after each section rather than waiting until the end.

[discrete]
= 1. The Interface and Abstract Class

Create a java file called `Timed.java` and paste this code into it.
Be sure to format the code using the `astyle` command.

[source]
----
public interface Timed {
    int getDuration();
}
----

Create a java file called `CampusEvent.java` with the following starter code:

[source]
----
public abstract class CampusEvent implements Timed {
    private String name;

    public CampusEvent(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}
----

Answer these questions in `answers.txt`:

1. Why can we not create an object using `new CampusEvent("Concert")`?
2. Why can `CampusEvent` omit the implementation of `getDuration()`?
3. What must a concrete subclass do to satisfy the `Timed` interface?

= 2. Implement Two Subclasses

Create two more java files: `Workshop.java` and `Film.java`.

For `Workshop.java`, implement the following subclass:

- Extends `CampusEvent`.
- Has a private integer field representing the number of sessions.
- Each session lasts 30 minutes.
- Constructor: `Workshop(String name, int sessions)`.
- Implements `getDuration()` by returning the total duration of all sessions.

For `Film.java`, implement the following subclass:

- Extends `CampusEvent`.
- Has a private integer field representing its duration in minutes.
- Constructor: `Film(String name, int minutes)`.
- Implements `getDuration()` by returning its duration.

Remember to use `super(name)` and `@Override` where appropriate.

= 3. Test Polymorphism

Create `EventLab.java` with the following code:

[source, subs="quotes"]
----
public class EventLab {
    public static void main(String[] args) {
        CampusEvent[] events = new CampusEvent[2];
        events[0] = new Workshop("Painting", 3);
        events[1] = new Film("Documentary", 80);

        for (int i = 0; i < events.length; i++) {
            System.out.println(events[i].getName() + ": "
                    + events[i].getDuration() + " minutes");
        }
    }
}
----

Compile all your java files and run `java EventLab`. You should see this output:

[source]
----
Painting: 90 minutes
Documentary: 80 minutes
----

In your `answers.txt` file, explain why the same call to `getDuration()` behaves
differently for the two objects.

= 4. Read Events from a File


Copy the following code into the `Main.java` file.
Follow the same instructions from part 2 to format your code before you begin programming.

[source, subs="quotes"]
----
public class Main {
    public static void main(String[] args) {
        LibraryItem item = new LibraryItem("Map", 5);
        Book book = new Book("The Hobbit", 12, "J.R.R. Tolkien");

        System.out.println(item.describe());
        System.out.println(book.describe());

        // TODO 7: Make a second Book of your choice.
        // Print its title, author, and description.

        // TODO 8: Predict the output of the next two lines.
        LibraryItem anotherItem = book;
        System.out.println(anotherItem.describe());
    }
}
----

Compile/run from the directory containing all three files:

[source, subs="quotes"]
----
javac LibraryItem.java Book.java Main.java
java Main
----

Expected output for the supplied objects:

[source, subs="quotes"]
----
Item #5: Map
Book #12: The Hobbit by J.R.R. Tolkien
----

The later output depends on your own second book; the final `anotherItem.describe()` 
should use the `Book` version.

Answer the following questions:

1. Which class is the superclass? Which is the subclass?
2. Explain why `super(title, id)` belongs in the `Book` constructor.
3. Is `Book` an example of an **is-a** or **has-a** relationship with `LibraryItem`?
4. Why does `anotherItem.describe()` call the `Book` version even though `anotherItem` is declared as `LibraryItem`?
